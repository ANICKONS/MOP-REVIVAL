# План работ: MOPR 6.0

Задачи идут по этапам из `requirements.md`; внутри этапа — по порядку зависимостей. Ссылки «§N» — разделы
`design.md`. Общие правила для каждой задачи:
- сборка без предупреждений против настоящих сборок игры;
- `dotnet test MOPR6\Tests` проходит;
- код 5.x не меняется;
- коммиты делает автор; автор дал полную свободу: задачи выполняются подряд, на контрольных точках — отчёт без ожидания.
