# Хост систем, ошибки, настройки

## Что делает

- `Mod/Host/SystemHost.cs` ставит, снимает, приостанавливает и возобновляет системы, тикает их раз в 0,25 с
  (часы мода — `Time.unscaledTime`, в детерминированных прогонах такт приходится на тот же кадр).
- Состояния системы — ядро `Core/src/Host/SystemState.cs`: `NotInstalled`, `Installed (On|Verify)`, `Suspended`,
  `Removed`, `Tripped`.
- Ошибка в хуке: `Optimization.Fail` пишет её в `ErrorSink` (один раз на место и тип, со стеком; дальше счётчик) и
  сразу останавливает хуки системы (`Live = false`, работает оригинал). Решение принимает хост в конце кадра:
  больше 3 отказов за 60 с (`FailurePolicy`) — система снимается, её изменения возвращаются, в консоли строка на
  языке игрока. Иначе она продолжает работу со следующего такта.
- Главный выключатель (Т13.2): `SystemHost.StopAll` снимает все системы в обратном порядке и возвращает журнал.

## Настройки, язык, консоль (задача 27)

- Страница — `Mod/UI/SettingsPage.cs`: информация (версия, PREVIEW, конфликт с 5.x), язык, главный выключатель,
  пять точных оптимизаций по отдельности, режим проверки, проверка обновлений, импорт 5.x, кнопки «отчёт» и
  GitHub. Всё применяется сразу (Install/Remove через хост), в том числе в игре; настроек, которым нужен
  перезапуск, на этапе 1 нет.
- ID настроек: `enabled`, `verify`, `checkUpdates`, `language`, `sys.<id системы>`. Файл —
  `Mods\Config\Mod Settings\MOPR6\settings.json`; файлы 5.x (`Mod Settings\MOPR`) только читаются командой
  `mopr import5` (Т1.4).
- Локализация ru/en/pl — инфраструктура 5.x (`Mod/Localization/Loc.cs`, `LocalizedSettings.cs`), ключи новые:
  38 ключей интерфейса и 38 ключей консоли, во всех трёх языках, плейсхолдеры совпадают. Язык переключается на
  лету; отчёт и ответы для TestBot — всегда на английском.
- Консоль `mopr`: `help`, `status`, `on`/`off` (главный выключатель), `on|off|verify ID|all` (одна система на
  сеанс), `verify` (расхождения), `restore`, `report`, `import5`, `catalog`, `update`, `errors`, `ledger`,
  `barrier`, `lang`; для стенда `probe …` и старое `sys …`.
- Порядок MSCLoader 1.4: `ModSettings` → `OnMenuLoad` → сохранённые значения → `ModSettingsLoaded`. Поэтому язык
  при построении страницы читается из своего `settings.json`.
- `Newtonsoft.Json.Linq` в игре не работает: `JObject` требует `System.ComponentModel.INotifyPropertyChanging`,
  которого нет в профиле Mono игры (`TypeLoadException` при компиляции метода, `catch` внутри него не помогает).
  Файлы настроек читаются типизированными классами (`Mod/UI/SettingsFile.cs`).

## Отчёт и обновления (задача 28)

- `mopr report` и кнопка — `Mod Settings\MOPR6\report-<дата>.txt`, на английском: версия и PREVIEW, хеш
  `Assembly-CSharp` против инвентаря, Unity, MSCLoader, ОС, настройки, все системы со счётчиками и расхождениями,
  журнал и барьер, ошибки с числом повторов и стеком первой, каталог, ID других модов, путь лога. Профиль
  пользователя заменяется на `%USERPROFILE%`, имя пользователя как часть пути — на `%USERNAME%`
  (`Core/src/Diagnostics/Redact.cs`, тесты `ReportTests`). Содержимого сейва в отчёте нет.
- Проверка обновлений — перенос 5.x (`Mod/UI/UpdateChecker.cs`, WinHTTP `SystemHttp.cs`). Смотрит список релизов
  репозитория; выбор — `Core/src/UpdateCheck.cs` (тесты там же): preview видит более новые `v6.0.0-preview.N` и
  релизы 6.x, релизная сборка — только релизы 6.x; релизы 5.x того же репозитория не учитываются. Ссылка: для
  preview — страница релиза на GitHub, для релиза — Nexus Mods.
- Экран загрузки перенесётся с этапом 4: сейчас MOPR6 настраивает сцену за миллисекунды (время пишется в лог
  строкой `game scene set up … in N ms`), показывать нечего — экран мелькнул бы на один кадр.

## Что проверено

- Модульные тесты: состояния системы, `FailurePolicy`, `ErrorSink`, правило `catch` (Roslyn), `Redact`,
  `UpdateCheck` — 118 тестов проходят.
- `probe-throw` (2026-10-29): тестовая система снята после 4-го отказа, её изменения возвращены, остальные
  работают.
- `load-quit -WithMopr5`: при включённом 5.x MOPR6 ничего не ставит и пишет предупреждение.
- `settings-check` (прогон `sc2`, 2026-10-29):
  - зонд держит 76 изменений; `mopr off` — «76 changes returned, 0 could not be», журнал пуст, `mopr on engine.fsm`
    при выключенном главном выключателе отказывает; `mopr on` возвращает все системы;
  - `verify all` 15 с у дома — 0 расхождений;
  - страница «как пользователь» (`modsetting`): язык, главный выключатель (ответ в консоли по-русски), IK off/on;
  - `mopr update` — ответ GitHub получен и разобран («для этой сборки опубликованных версий пока нет»);
  - `mopr import5` без 5.x — «настройки не найдены»; `help` по-русски, переключение на польский и английский;
  - ошибок мода нет.
